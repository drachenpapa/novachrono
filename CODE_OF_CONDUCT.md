# Code of Conduct

This project is intended to be a respectful and constructive space for everyone.

Harassment, discrimination, personal attacks, or abusive behavior are not tolerated. This applies to issues, pull requests, discussions, and other project-related communication.

Disagreement is fine. Please keep criticism focused on ideas, code, and technical decisions rather than on people.

If you encounter a violation of this code or have concerns about the behavior of others, please [report it to the project maintainer](mailto:drachenpapa.dev@gmail.com).
